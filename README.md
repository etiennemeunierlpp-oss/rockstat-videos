# rockstat-videos
Vidéos TikTok « argent facile dans GTA 6 » pour @rockstat433, 100 % automatiques.
- Procédure : `TACHE_ARGENT.md` (lue par les tâches programmées de 8 h 12 et 14 h 41).
- `queue/` : scripts à rendre → `.github/workflows/render.yml` (voix, montage, MP4 sur la branche `v-<slug>`).
- `.github/workflows/menage.yml` : supprime chaque nuit les vidéos publiées et la file traitée.
- `atelier/` : outils de montage (`montage.py` = choix des plans sans répétition).
